# Antislop audit 001

Scope: `README.md`, `profile-hero-light.svg`, and `profile-hero-dark.svg`

Design read: GitHub profile header for visitors browsing public repositories, using the established qray.dev visual language. ENERGY 1 / RHYTHM 1 / MOTION 1.

## Finding

1. **HIGH, R-03: Small banner labels become unreadable on narrow screens.** The 1200 px SVG scales as one image inside GitHub's mobile content column, reducing the 12–24 px labels to roughly 3–7 CSS pixels. Keep only large essential text in the shared banner, or provide a dedicated narrow-layout asset selected through the README picture element.

## Checks that passed

- R-01 / R-29: The palette comes directly from qray.dev and is limited to cream and olive tones.
- R-04 / R-22: The geometric `q` is the site's existing favicon mark; the horizon echoes the site's asteroid scene.
- R-06: Georgia carries the site wordmark, sans-serif carries the role, and monospace is confined to work-index metadata.
- R-17 / R-18 / R-36 / R-38: No statistics, testimonials, names, dates, employers, locations, or unverifiable claims appear.
- R-21 / R-34: The README selects separate rendered light and dark SVGs from the viewer's theme preference.
- R-24 / R-26 / R-32: The README introduces no navigation or interactive controls.
- R-25: All text pairings pass WCAG AA. Ratios are 13.25:1 (`#20281c` on `#f5f0d5`), 5.28:1 (`#5b6651` on `#f5f0d5`), 12.28:1 (`#f4e7b7` on `#20281c`), and 8.51:1 (`#bdc5ae` on `#20281c`).
- R-30: The design follows qray.dev's own identity rather than another product.
- R-31: Color, type, layout, spacing, and imagery all trace to the source site and the decision to let GitHub display pinned repositories natively.

No audit-driven changes have been applied.
